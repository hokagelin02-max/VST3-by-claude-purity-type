# TapeRomp CT-7 — лёгкий VST3-синт в стиле Purity

35 пресетов в 7 вкладках: **BELLS, ARPS, E-PIANO, BRASS, STRINGS, LEADS, FAST**.
Под plugg / darkplugg / trap / futuristic / glo. Интерфейс — старый кассетный магнитофон
(катушки крутятся, пока играют ноты). Все звуки синтезируются, сэмплов нет → плагин маленький и лёгкий.

## Как собрать (Windows)

1. Установи **Visual Studio 2022 Community** (галочка «Разработка классических приложений на C++»), **CMake** и **Git**.
2. В папке проекта открой терминал и выполни:

```
cmake -B build -G "Visual Studio 17 2022"
cmake --build build --config Release
```

3. Готовый `TapeRomp.vst3` появится в `build/TapeRomp_artefacts/Release/VST3/`
   (после сборки он копируется в `C:\Program Files\Common Files\VST3`; для этого терминал нужно запускать от администратора).
4. В FL Studio / Ableton: пересканируй плагины.

Для macOS/Linux: `cmake -B build && cmake --build build --config Release`.
JUCE скачается сам при первой настройке (нужен интернет).

## Управление

- **Вкладки сверху** — категории. Клик по вкладке сразу загружает первый пресет категории.
- **Список справа** — пресеты выбранной категории.
- **TONE** — яркость (фильтр ±2 октавы), **RELEASE** — длина хвоста, **REVERB**, **VOLUME**.
- **ARP** — арпеджиатор. Включается сам на пресетах из ARPS и выключается на остальных; можно переключить вручную.
  Скорость: 1/4, 1/8, 1/16, 1/32 (от темпа хоста). Рисунок арпеджио задан в пресете (вверх, вниз, вверх-вниз, +октава).

## Где что менять

- `Source/Presets.h` — все пресеты (таблица, добавлять строки очень просто).
- `Source/SynthEngine.h` — звуковой движок (8 голосов).
- `Source/PluginEditor.cpp` — внешний вид.

## Важно

- Код не компилировался и не тестировался в среде, где я его писал: при первой сборке возможны мелкие правки.
- Звук — синтез, а не сэмплы Purity, поэтому он будет другим. Пресеты это стартовая точка, подкрути под свой вкус.
- Лицензия JUCE: бесплатно для некоммерческого использования (AGPL / JUCE Personal); для продажи плагина нужна коммерческая лицензия JUCE.

## Без установки Visual Studio: готовый .exe через GitHub

1. Зарегистрируйся на github.com, создай новый репозиторий и загрузи в него содержимое этой папки (включая скрытую папку `.github`).
2. Открой вкладку **Actions**, дождись зелёной галочки (10-15 минут).
3. Открой завершённый запуск и скачай внизу архив **TapeRomp-Setup**, внутри `TapeRomp-Setup.exe`.
4. Запусти установщик, перезапусти DAW и пересканируй плагины.

Windows может показать предупреждение SmartScreen, потому что установщик не подписан: «Подробнее» -> «Выполнить в любом случае».
