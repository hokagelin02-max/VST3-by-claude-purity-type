# TapeRomp CT-7 — лёгкий VST3-синт в стиле Purity

35 пресетов в 7 вкладках: **BELLS, ARPS, E-PIANO, BRASS, STRINGS, LEADS, FAST**.
Под plugg / darkplugg / trap / futuristic / glo. Интерфейс — старый кассетный магнитофон
(катушки крутятся, пока играют ноты). Все звуки синтезируются, сэмплов нет → плагин маленький и лёгкий.

3. Открой завершённый запуск и скачай внизу архив **TapeRomp-Setup**, внутри `TapeRomp-Setup.exe`.
4. Запусти установщик, перезапусти DAW и пересканируй плагины.

Windows может показать предупреждение SmartScreen, потому что установщик не подписан: «Подробнее» -> «Выполнить в любом случае».
